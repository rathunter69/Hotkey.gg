Navigate & Select

tutorial

Every other skill starts with getting to the cell and selecting the right block. This is the ten seconds a banker saves a hundred times a day.

Functions & keys tested
Ctrl+arrowShift+arrowCtrl+Shift+arrowCtrl+SpaceShift+SpaceCtrl+AF5 → SpecialCtrl+C / Ctrl+VCtrl+S
What is on the grid
A 20-row grid: a walled corridor snakes from the top-left corner to a sales table (eight regions by four quarters plus a full year) parked in the far corner. A marked home bay sits at A1.
How it is gamified

Three steps: the corridor, the captures, the run home. Checkpoints light as you pass.

Taught. Guide open; each straightaway of the corridor is one Ctrl+arrow; then the table asks for a row, a column, the whole block, and every typed number.

★ The pro move: Every hall in one press, never cell by cell.

The player’s steps
  1. Fly each hall in one press
  2. Land on the model block
  3. Select the West row
  4. Select the Q3 column
  5. Select the whole table
  6. Select every typed figure (Go To Special)
  7. Copy the block
  8. Deliver it to the home bay
  9. Save
