## The rules, distilled (binding for v5.1)

1. **Full page, one story.** The 20×10 grid is filled with one coherent artifact a real person would produce or
   fix; the win state is sendable. No 300-row pages, no scrolling, no islands of exercise blocks.
2. **Fulsome, not thin.** Three steps of three to four outcomes on that one page; a skilled player needs 60–150
   seconds. Sibling mechanics share a drill (rows + columns, transpose + multiply + values, TRIM + PROPER +
   LEFT/MID + CONCAT). "No four-keystroke wins."
3. **Rebuild, don't retype; consequences visible.** Formulas are rebuilt from neighbours and assumptions; a
   total moves when a line is inserted; a paste that should be values visibly breaks if it is not.
4. **Random enough to be un-maxable.** Layout, which row is broken, which vendor is renamed: the player learns
   the move, not the answer.
5. **Loud location cues, desk language.** Red "<<< Insert row above" text where the player must act; the copy
   says stale data, duplicate rows, staged lines, destination range, hardcodes, links — never imposter,
   squatter, cargo, bay, dock.
6. **The ☆ is a choice** — a skippable habit that saves time (Ctrl+Shift+↓ before the copy, one Go To Special
   instead of hunting), never something earned by finishing.
7. **Variety inside the drill** — three uses of the same key are three different stories.
