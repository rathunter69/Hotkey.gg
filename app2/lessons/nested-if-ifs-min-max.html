Lesson 53: Nested IF, IFS, and MIN and MAX instead

Formulas and functions · Logic · medium · Paid

undefined

What you will do

  1. A manager earns a bonus for every day the site clears a tier: the more washes, the bigger the step, which is why the tests have to run from the top tier down. Select the tier table J5:K8 on Summary: 250 washes earn $50 a day, 300 earn $100 and 350 earn $150.
  2. A nested IF puts the next IF where the false answer goes, so the tests run from the top tier down and the last 0 is what is left. Build the tower in I5, =IF(C5>=350,150,IF(C5>=300,100,IF(C5>=250,50,0))), and fill it down to I10.
  3. Open I5 with F2 and count the parentheses that close the tower, then Esc: that count is what a reviewer has to check.
  4. IFS takes the tests in pairs, a test and its answer, and returns the answer beside the first test that holds; TRUE at the end catches everything left. Same answers as the tower, read top to bottom. Replace the tower: with I5:I10 selected, type =IFS(C5>=350,150,C5>=300,100,C5>=250,50,TRUE,0) and press Ctrl+Enter.
  5. MAX(x,0) floors a figure at zero and MIN(x,150) caps it at 150, each in one call. When a test only floors or caps, MAX or MIN says it without an IF. Floor the gap with MAX: select G5:G10 and rewrite it as =MAX(C5-D5,0) with Ctrl+Enter; the figures do not move.
  6. When the test picks from a list of bands, IFS says it; when it only caps or floors, MIN or MAX does. In Chapter 4 a lookup on the tier table replaces both. Head the column you kept: type Bonus ($/day) in I4.
  7. Does it tie? Watch Domain’s washes in C5 rise to 360 and its bonus in I5 step up to $150.
