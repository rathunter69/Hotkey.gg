Lesson 32: Whole rows, columns and the sheet

Foundations · Selecting · easy · Free

Formatting and structure work lands on whole rows, whole columns or the whole block at once. In this lesson you select the Units column, the header row, the report region and the entire sheet without touching the mouse. These selections are the setup step for almost every command that follows.

What you will do

  1. Select the whole of column C, the Units column, with Ctrl+Space.
  2. Move to A2 and select the whole header row with Shift+Space.
  3. From B4, select the report block with one Ctrl+A.
  4. Ctrl+A selects the current region; pressed again it selects the whole sheet. Press Ctrl+A a second time to select the entire sheet.
  5. Snap back to just the report block with Ctrl+Shift+Space.
