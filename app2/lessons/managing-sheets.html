Lesson 3: Sheets: insert, rename and delete

Foundations · How Excel works · easy · Free

A workbook you inherit rarely arrives tidy: a tab still called Sheet2, a stale copy nobody deleted, no summary up front. In this lesson you rename, delete, insert and move worksheets from the Home tab, with the sheet keys you already know. Every model gets tidied this way, and the names you set are the names every cross-sheet reference will carry, so get them right early.

What you will do

  1. Rename Sheet, under Home › Format (Alt, H, O, R), opens the active tab's name with it selected: type the new name and press Enter. Move to Sheet2 and rename it Costs.
  2. Delete Sheet, under Home › Delete (Alt, H, D, S), removes the active sheet; Excel asks first when it holds anything, since a deleted sheet cannot be undone. Delete the Old sheet, the stale copy at the end, and confirm.
  3. Shift+F11 inserts a new worksheet in front of the active one and makes it active, named with the next free number. From Costs, insert a new worksheet; it arrives as Sheet3, between Sales and Costs.
  4. Rename the new sheet Summary.
  5. Move or Copy Sheet (Alt, H, O, M) moves the active sheet: ↑ ↓ pick the sheet it will sit before, or (move to end), then Enter. Move Summary to the front of the workbook, before Sales.
