Lesson 66: Managing rules

Formatting and presentation · Conditional formatting · medium · Paid

Rules pile up, overlap and outlive the ranges they were written for, and a page with six rules nobody remembers is a page nobody trusts. Manage Rules lists them, shows their ranges, and lets you delete, reorder and set Stop If True. Tidy the rules on the P&L to the two the page needs. The key is Alt H L R.

What you will do

  1. On the P&L, open Manage Rules with Alt, H, L, R and read the four rules and the ranges they apply to.
  2. Delete the row rule on B7:E9, now that no row carries a flag.
  3. Select the duplicate-values rule on B7:B35 with ↓ and delete it, now that the labels are fixed; close the list with Enter.
  4. A rule written for C27:E29 misses the growth line under it. Add the same rule over C27:E30, and the old one becomes a duplicate to delete. Select the margins and growth C27:E30 and add the rule again: Less Than 0, Red Text.
  5. In Manage Rules, select the old margin rule on C27:E29, third in the list, and delete it.
  6. Rules run from the top. Move Up (U) puts the checks rule first, and Stop If True (S) means that where a check fires, nothing below it paints the cell. Move the checks rule to the top with U, tick Stop If True with S, and press Enter.
  7. Does it tie? Watch total revenue in C10 typed over as 32000: the checks rule fires on C39, and nothing else does.
