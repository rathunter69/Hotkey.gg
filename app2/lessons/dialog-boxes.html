Lesson 13: Dialog boxes: Format Cells

Foundations · The Ribbon and dialogs · medium · Free

Some commands do not act at once: they open a dialog box and wait for your choice. In this lesson you open Format Cells with Ctrl+1 and from the Ribbon to give the Weekly Sales Report proper number formats, which change how a value is shown, never the value itself. Number formatting is the difference between raw figures and a report someone can read.

What you will do

  1. Ctrl+1 opens the Format Cells dialog box, and here the first letter of a category applies it: N is Number. Select the Sales figures B3:B8 and apply the Number format.
  2. Select the Growth figures C3:C7 and apply the Percentage format (P).
  3. The Ribbon reaches the same dialog box: Alt, H, O opens the Format menu and E chooses Format Cells. Open Format Cells on the Total in B8 through the Ribbon and apply Currency (C).
