Lesson 147: Case outputs side by side: a data table on the switch, and the sticky IF

Data and Lookups · Scenarios and sensitivity · hard · Paid

The board wants all three cases on one page, and a switch shows one at a time. The clean way to hold them all is a one-way Data Table whose row input is the switch itself: 1, 2 and 3 across the top, the outputs down the side, and the table runs the model three times. The other is the sticky IF, a cell that reads the live output when its case is on and otherwise reads itself, which needs iteration on. Build both; keep the table. The key is Alt A W T.

What you will do

  1. Type the case numbers across D50:F50: 1, 2 and 3.
  2. Name each column from the list: D49:F49 =INDEX(Lists!$L$5:$L$7,D50) with Ctrl+Enter.
  3. Link the outputs down the side: C51 =C17, C52 =C18, C53 =C22 and C54 =C24.
  4. Select C50:F54, press Alt, A, W, T, set the Row input cell to the switch, C11, and press Enter.
  5. A sticky IF reads the live output when its case is on and its own cell when it is not, so it holds the last value it saw. A cell that reads itself is a circular reference, so it needs iterative calculation on. Turn on iterative calculation (Alt, F, T, I, Enter) and write the sticky IF in H54: =IF($C$11=2,$C$24,H54).
  6. Set the picker in C10 to Downside: EBITDA falls, and H54 holds Base’s figure, a hardcode that looks like a formula.
  7. Keep the table, not the sticky cell: picker back to Base, H54 cleared, and iterative calculation off again.
  8. On Q&A, answer questions 9 and 10: F13 =Scenarios!F54, F14 =Scenarios!C46, and mark both Answered in E13:E14.
  9. Does it tie? Watch Downside’s washes a day go from 220 to 200: its column of the table moves while Base is live.
