Lesson 57: Assessment: the weekly report, timed

Foundations · Project and assessment · hard · Free

Same report, fresh week, five minutes on the clock. The Raw sheet holds week two’s export and the Report sheet is blank: title, headers, live links, totals, Number format, borders, frozen header. You built this once slowly — now build it like it’s Monday morning.

What you will do

  1. Type Week 2 Sales Report into A1 and make it bold.
  2. Build the header row: Day in A2, Sales in B2, Units in C2, all bold.
  3. Link the day names: enter =Raw!A3 in A3 and fill it down to A7.
  4. Link the figures: enter =Raw!B3 in B3 and =Raw!C3 in C3, then fill B3:C7 down.
  5. Type Total into A8, then select B3:C8 and AutoSum both columns at once.
  6. Give the Sales column B3:B8 the Number format from Ctrl+1.
  7. Rule the table with All Borders on A2:C8.
  8. Freeze the top row to finish the report.
