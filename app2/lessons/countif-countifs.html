Lesson 92: COUNTIF and COUNTIFS

Formulas and functions · Math and aggregation · medium · Paid

undefined

What you will do

  1. COUNTIF(range, criteria) counts the cells in the range that match the criteria, so =COUNTIF(Transactions!$B$5:$B$94,B15) counts the export rows whose site is the code in B15. Anchor the range with $ and leave B15 relative, and one formula serves all six sites. Count the washes by site: select C15:C20, type =COUNTIF(Transactions!$B$5:$B$94,B15) and press Ctrl+Enter.
  2. The same COUNTIF by package: C25:C27 =COUNTIF(Transactions!$C$5:$C$94,B25) with Ctrl+Enter, the package letters as the criteria.
  3. COUNTIFS takes the pairs one after another and counts a row only when every pair matches. A criteria in quotes can compare: "<>" means not blank, so the member column with "<>" counts member washes. In D15:D20 count each site’s member washes: COUNTIFS on the site, then the member column Transactions!$D$5:$D$94 with "<>".
  4. Retail washes with COUNTIFS: E15:E20 on the site with the amounts ">0", then D25:D27 on the package with the member column "".
  5. Two pairs on the same range make a band: ">=15" with "<20" counts the $15 tickets and leaves the $20 ones to the next band. The edges are where a band count goes wrong, because a > where >= belongs drops every ticket sitting exactly on the edge. Count the tickets in C34:C36: "<15", then ">=15" with "<20", then ">=20", and color the three green, since they read only Transactions.
  6. Check the bands in C37: =SUM(C34:C36)-COUNT(Transactions!$E$5:$E$94) reads 0 when every numeric ticket sits in one band.
  7. In a block, anchor the criteria both ways: $B41 keeps the column of site codes as the formula moves right, and C$40 keeps the row of package letters as it moves down. One formula then fills the whole block. Fill the site by package block C41:E46 in one Ctrl+Enter: COUNTIFS on the site $B41 and the package C$40.
  8. Total the three blocks with AutoSum: select each block with its empty total row, C41:E47, C25:D28 and C15:E21, and press Alt+=.
  9. Write the checks: C80 =C21-C28 and C81 =C21-COUNTA(Transactions!$A$5:$A$94); both read (2), two washes the site codes miss.
  10. Does it tie? Watch the first wash in Transactions!C5 change from B to U, and Basic and Ultimate in C25:C27 shift by one each.
