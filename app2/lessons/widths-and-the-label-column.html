Lesson 55: Widths and the label column

Formatting and presentation · The page a buyer reads · medium · Paid

A financial page has a shape: a narrow margin in column A, labels in B fitted to the longest one, and every figure column the same width. The export has 8.43 everywhere and codes in A. Set the margin, fit the labels, set one width across the years, and see why the period columns are set by hand and the label column by AutoFit. The key is Alt H O W.

What you will do

  1. Column A is a margin: it holds the title and the units line and nothing under them, so it only needs to be narrow. Column Width (Alt, H, O, W) takes a width in characters. Make column A the margin: Alt, H, O, W, width 2.
  2. Period columns are set by hand to one width, so FY24A, FY25A and FY26E read as equals. AutoFit would give each year its own width. Select columns C:E and give the three years one width, 12.
  3. Back at A1 with Ctrl+Home, make row 1 a little taller for the title: Alt, H, O, H, height 24.
  4. The label column is fitted to its labels by AutoFit, over the labels only: the title and the source line run long on purpose and would stretch it. Select B4:B35 and AutoFit with Alt, H, O, I. Fit column B to its labels, not the title or the source: select B4:B35 and AutoFit with Alt, H, O, I.
  5. Freeze the panes at C5 with Alt, W, F, F, so the labels and the timeline stay in view as the page scrolls.
  6. Does it tie? Watch E7 change to 27000: the widths hold and E24 answers.
