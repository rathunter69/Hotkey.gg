Lesson 152: Challenge: a model’s toggles named and wired

Data and Lookups · Names and structure · hard · Paid

A model with its switch read by address, a broken Ticket and a stray in the Name Manager. Name the switch and the key inputs, fix the names, drive the picker by name and paste the list on Inputs.

What you will do

  1. Name the switch on Scenarios C11 Case, Inputs C5 Cost_Per_Wash and the case list on Lists L5:L7 Cases.
  2. In the Name Manager point Ticket at Inputs C15, delete the stray Ticket_old and close it.
  3. Make the live column G5:G8 and the check in C58 on Scenarios read the switch as Case.
  4. Point the case picker in Scenarios C10 at the name: Data Validation, List, Source =Cases.
  5. Paste the names list on Inputs from B19 with F3 and Paste List.
