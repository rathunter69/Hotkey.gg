Lesson 20: Challenge: reshape the report

Foundations · Structure · medium · Free

undefined

What you will do

  1. The Depot site opened: insert a row inside the block, above the last site, and enter Depot, 1,800 kWh, $828 revenue, $234 energy cost.
  2. Old code in column H is the old platform’s site code: delete the whole column, not just its cells.
  3. The six figure columns B:G are six different widths: select them from the header row and set Column Width 12.
  4. A figure column is hidden — a buyer’s analyst would find it and wonder: unhide it inside the same selection.
  5. Gross profit and Avg price in E:F are working columns: group them rather than hiding them.
  6. Freeze the panes at B4 so the title, units, header row and site column stay in view.
