Lesson 119: XLOOKUP: exact, not-found, two-way

Data and lookups · Lookups · medium · Paid

XLOOKUP is the modern lookup: the key, the column to search, the column to return, and an optional message for a miss. It is exact by default, looks in any direction, and nests for a two-way answer. Banks lag versions, so most models you inherit still read INDEX/MATCH; learn XLOOKUP so you can use it where the file allows and read it where you find it. The key is XLOOKUP.

What you will do

  1. XLOOKUP(key, lookup range, return range) finds the key in the first range and returns the cell beside it in the second. No column is counted and no FALSE is needed, because exact is the default. Capacity by XLOOKUP in Summary J5:J10: =XLOOKUP(B5,Lists!$B$5:$B$10,Lists!$F$5:$F$10).
  2. In J15, look up a code that isn’t on Lists, AUS-XXX, and read #N/A.
  3. The fourth argument is what XLOOKUP returns when the key isn’t there. A message in words tells the reader the code is missing; a #N/A only tells them something broke. Add the fourth argument to J15, "Not listed", so the miss says so in words.
  4. The lookup range and the return range are separate, so the return can sit left of the key: search the names, return the codes, no rearranging. In J16, look up Airport’s code right to left: search the names in Lists!$C$5:$C$10, return the codes.
  5. An XLOOKUP can return a whole row: the inner one finds the site’s row of the cube, and the outer one finds the week across the top and returns that cell of the row. Best practice: XLOOKUP where the file is yours and the version allows, INDEX/MATCH in anything a bank’s model will read; XMATCH is MATCH with exact as the default and goes inside INDEX the same way. Nest two XLOOKUPs in J19 for the two-way answer, and read it match C38.
  6. Does it tie? Watch Domain’s capacity on Lists move to 130 and J5 follow it.
