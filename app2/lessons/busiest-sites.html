Lesson 94: MAXIFS, MINIFS, LARGE, SMALL and RANK

Formulas and functions · Math and aggregation · medium · Paid

"Which site was busiest, and on which day?" MAXIFS finds the biggest value that meets a condition and MINIFS the smallest; LARGE and SMALL find the nth biggest or smallest in a range; RANK places every site in order. Together they turn the site block into a league table without sorting anything, which matters because the block has to stay where every link expects it. The key is LARGE.

What you will do

  1. LARGE(array, k) returns the kth biggest value in the range, so k of 1, 2 and 3 is a top three that rereads itself whenever a count moves. SMALL counts up from the smallest the same way. Anchor the range, since every line reads the same six sites. The top three site totals in J15:J17: =LARGE($C$15:$C$20,1), then 2, then 3.
  2. And the bottom one under them in J18: =SMALL($C$15:$C$20,1).
  3. RANK(number, ref) gives a value’s place in the list, 1 for the biggest, and ties share a place. Read the order off K without sorting the block. Rank Domain in K15: =RANK(C15,$C$15:$C$20).
  4. Rank every site in K15:K20: the same RANK with Ctrl+Enter, and read the league table down K.
  5. MAXIFS(max_range, criteria_range, criteria) returns the largest value on the rows that meet the criteria, the same pairs COUNTIFS takes, and MINIFS the smallest. Daily holds one row per site per day, so the site’s code finds its busiest day. Each site’s busiest day in H15:H20: =MAXIFS(Daily!$D$5:$D$94,Daily!$B$5:$B$94,B15) with Ctrl+Enter.
  6. Each site’s quietest day in I15:I20, the same pairs with MINIFS.
  7. Does it tie? Watch Airport’s washes in C19 change to 25, and its rank in K19 and the top three in J15:J17 reorder.
