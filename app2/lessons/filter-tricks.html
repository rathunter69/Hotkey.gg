Lesson 128: Filter tricks: visible cells only, wildcards, skip blanks

Data and Lookups · Lists and tables · hard · Paid

A list does three things to the unwary: copy a block with rows hidden by hand and they come too, unless you select visible cells only first with Alt+;. Search for a site by part of its code and COUNTIF wants a wildcard, * for any run of characters and ? for exactly one. Paste a partial column over a full one and its blanks wipe what was there, unless Paste Special skips blanks. The key is Alt+;.

What you will do

  1. On Export sort, hide rows 20 to 34 by hand: Go To A20:A34 and press Ctrl+9.
  2. A copy of a block takes rows hidden by hand along with it. Alt+; selects the visible cells only, so the next Ctrl+C leaves the hidden rows behind; a filter does this on its own. Select the block A4:G94, press Alt+; for visible cells only, then Ctrl+C.
  3. Insert a sheet after Export sort, rename it Scratch and paste at A1: seventy-five rows and the header.
  4. Back on Export sort, the block is still selected: Ctrl+Shift+9 brings rows 20 to 34 back.
  5. In a criteria, * stands for any run of characters and ? for exactly one. "AUS-*" is every Austin code; "AUS-?O?" is a code whose middle letter of three is O. Beside the export, count with wildcards: J96 =COUNTIF(B5:B94,"AUS-*") and J97 =COUNTIF(B5:B94,"AUS-?O?").
  6. In J98, retail revenue for every code ending in R: =SUMIFS(F5:F94,B5:B94,"*R").
  7. Paste Special with Skip blanks (Ctrl+Alt+V, then B) leaves a blank cell of the copy out of the paste, so what sits under it stays. Without it, a partial column wipes the full one. On Export sort, copy the corrections I5:I94 and Paste Special them over the hours at G5 with Skip blanks ticked.
  8. Does it tie? Watch a typo in a Domain code drop the pattern count in J97 to 14 while J96 holds at 90.
