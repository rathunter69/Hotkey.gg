Lesson 142: A case toggle with CHOOSE and INDEX

Data and Lookups · Scenarios and sensitivity · medium · Paid

Three cases sit as three columns of inputs on Scenarios: washes a day per site, blended ticket, member share and sites at year end. One cell, the switch, says which column is live: CHOOSE(switch, a, b, c) returns the nth argument, and INDEX(range, switch) does the same from a range. The live column feeds the model, so every output moves when the switch does, and the picker in C10 drives the switch. Build the switch, the live column and the outputs. The key is CHOOSE.

What you will do

  1. A case switch is one cell that says which case is live, as a number. MATCH turns the picker’s name into that number, so a reader picks a word and the model reads 1, 2 or 3. Turn the picker into the switch: C11 =MATCH(C10,Lists!$L$5:$L$7,0), the case’s place in the list.
  2. CHOOSE(index, value1, value2, value3) returns the value in the place the index names. Anchor the switch with $ so every line reads the same cell. Live washes a day: G5 =CHOOSE($C$11,C5,D5,E5).
  3. INDEX(C6:E6, n) returns the nth cell of the range: the same answer as CHOOSE, from a range that grows by one column when a fourth case arrives. Live ticket, share and sites: select G6:G8 and enter =INDEX(C6:E6,$C$11) with Ctrl+Enter.
  4. Feed the model from the live column: C17 =G8*G5*Inputs!$C$10, washes a year, and C18 =C17*G6, revenue.
  5. Close the model: C22 =SUM(C18:C21), site contribution, and C24 =C22+C23, EBITDA.
  6. Light the live case: on C4:E8, a formula rule =C$4=$C$10 with a green fill.
  7. Name the case on the page: A1 =$C$10&" case: Clearcoat Express forecast, FY27".
  8. Does it tie? Watch the picker go to Downside: EBITDA falls, the green moves to column E and the title follows.
