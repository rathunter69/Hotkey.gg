Lesson 148: Challenge: a three-case model with a sensitivity table

Data and Lookups · Scenarios and sensitivity · hard · Paid

Fresh case inputs, and the switch, the live column and the tables are gone. Build the switch, both sensitivities on the driver, break-even by Goal Seek, and the cases side by side.

What you will do

  1. The switch and the live column: C11 =MATCH(C10,Lists!$L$5:$L$7,0), G5 by CHOOSE and G6:G8 by INDEX on $C$11.
  2. The one-way table: select C28:H29 and run a Data Table with the driver C13 as its Row input cell.
  3. The two-way table on C32:H37: Row input cell C13, Column input cell G7.
  4. Goal Seek C44 to 0 by changing C43, note the answer in C46 as 121, and put 250 back in C43.
  5. The cases side by side: select C50:F54 and run a Data Table with the switch C11 as its Row input cell.
