Lesson 116: The Name Manager

Data and Lookups · Names and structure · medium · Paid

The Name Manager lists every name in the file, what it holds, where it points and its scope, including the ones somebody left behind. This file has one: OldTicket, still pointing at the ticket’s old cell on Scenarios, which would quietly feed a formula the wrong price. Delete it, give the cost per wash the house spelling, and paste the list where the reviewer will see it. The key is Ctrl+F3.

What you will do

  1. Ctrl+F3 opens the Name Manager: one row per name, with its value, what it refers to and its scope. ↑ and ↓ pick a row. OldTicket points at the live ticket on Scenarios, a cell the model no longer treats as the input. Open the Name Manager with Ctrl+F3 and pick the stray, OldTicket.
  2. Delete (Alt+D) asks before it removes a name, and Enter answers OK. Read the Refers To column first: a stray that still points at a real cell is the dangerous kind, because nothing on the sheet looks broken. Delete OldTicket, confirm, and close the Name Manager.
  3. Edit (Alt+E) opens the picked name with its text selected, so typing replaces it; Enter saves, and every formula that reads the name follows it. Scope reads Workbook: a name defined this way works on every sheet, while a sheet copied with its names makes sheet-scoped duplicates, which is where strays like OldTicket come from. Rename CostPerWash to Cost_Per_Wash with Edit (Alt+E) in the Name Manager, then close it.
  4. Go To Cost_Per_Wash and land on the cost per wash on Inputs C5.
  5. Paste Name (F3) lists the names; Paste List (Alt+L) writes each one and what it refers to from the active cell down, as text. It is a snapshot, so paste it again whenever the names change. Paste the list of names under its heading on Inputs: F3 in B19, then Paste List.
  6. Does it tie? Watch Go To land on Ticket, a $13 ticket typed there, and EBITDA on Scenarios fall.
