Lesson 124: Sort and multi-level sort

Data and Lookups · Lists and tables · medium · Paid

Sorting rearranges rows, and it is the one list tool that changes the data’s order for good, so it runs on a copy of the export, never on the sheet the Summary reads. Alt, A, S, S opens the Sort dialog: a level for each column, smallest to largest or the other way, with My data has headers ticked. Sort the copy by site and then by date, then by retail revenue largest first to read the best days at the top. The key is Alt A S S.

What you will do

  1. Copy the export’s block, Export!A4:G94, headers and all seven columns: Ctrl+G to A4, select to G94 and press Ctrl+C.
  2. Insert a sheet right after Export (Ctrl+PgDn to Domain, Shift+F11) and rename it Export sort with Alt, H, O, R.
  3. Paste the block at A4 of Export sort, then Paste Special, Column widths (Ctrl+Alt+V, W) so every column reads as it did.
  4. Alt, A, S, S opens the Sort dialog on the block around the active cell. Each level is a column and an order; Excel sorts by the first level and uses the next one only to break ties, so site then date gives six runs of fifteen days. Sort the copy by Site A to Z, then add a level (Alt+A) for Date oldest to newest, and press OK.
  5. Sort the copy again by its F4 header, Retail revenue, Largest to Smallest, so the best days sit at the top.
  6. Does it tie? Watch the copy’s best day in F5 change to $4,000 while the export’s own rows stay as they came.
