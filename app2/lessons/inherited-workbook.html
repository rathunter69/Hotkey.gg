Lesson 1: The workbook the managers sent

Foundations · Open and set up · easy · Free

This is the Austin cluster’s weekly workbook exactly as ops sent it: five sites, two weeks of daily wash counts on the Raw tab, and the leftovers. First, learn to move: the arrow keys go one cell at a time, and Ctrl and an arrow jumps to the edge of the data. Then use those jumps to read each tab before you decide what happens to it: rename the one that holds the inputs, delete last week’s broken export, and add a Report sheet at the front. The tab names you set now are the ones every formula will carry. The key is Ctrl+↓.

What you will do

  1. The arrow keys move one cell per press. Ctrl and an arrow jumps to the edge of the data in one press (down, up, left or right), and the Name Box, left of the formula bar, shows where you landed. Walk down the dates with ↓ five times, then jump the rest of the way with Ctrl+↓ until the Name Box reads A61.
  2. Ctrl+↑ jumps to the top of the data. Ctrl+Home takes you home to A1 from anywhere on the sheet, which is the one to remember when you get lost in a big file. Come back up the same way: ↑ five times, then Ctrl+↑ to A1.
  3. The same jump works sideways. Left, right, up, down: four keys that replace almost all of your scrolling. Across the headers: Ctrl+→ to the last column, F1, then Ctrl+← back to A1.
  4. A workbook is the file, and the tabs along the bottom are its sheets: Ctrl+PgDn walks them to the right, Ctrl+PgUp to the left. A jump down column A reads a sheet’s labels without scrolling, and the jump stops at the blank row 2 on the way. Move to Sheet2 with Ctrl+PgDn and jump down its labels with Ctrl+↓ to A15: a cost per wash, a target ticket, a fee rate.
  5. Rename Sheet is Home › Format › Rename (Alt, H, O, R): type the new name and press Enter. Every formula that points at this sheet will carry the name you type now, so name it once and name it right. Those labels are the inputs the report runs on, so rename the Sheet2 tab to Inputs.
  6. One jump down a column tells you how far the data runs and what it ends on. Data that ends in #N/A is an export that broke on the way out, and nobody should be reading it. On the next tab, Old wk37, jump down column A with Ctrl+↓: it ends at A22 on #N/A, an export that died halfway.
  7. Delete Sheet (Alt, H, D, S) removes the active sheet; Excel asks first because it can’t be undone. Stale data left in a file gets read as if it were current, so it comes out. Nothing warns you when other tabs read the one you delete (their formulas turn to #REF!), so on a live model you search the workbook for the tab’s name first (3.6.3). Delete the Old wk37 tab: it’s last week’s export, half of it broken, and the live numbers are on Raw.
  8. The grid shows a result; the formula bar shows where it came from, and that’s the one a reviewer reads. Three steps down to the Domain row and one jump across put you on it. Costs is open now: jump to the Domain total in E4, where the formula bar shows =B4+C4+D4.
  9. Shift+F11 inserts a sheet, Alt, H, O, R names it, and Move or Copy Sheet (Alt, H, O, M) moves it: ↑ ↓ pick where it sits, Enter confirms. The output page goes first: tabs run the way a reader reads. Add a new sheet for the report, name it Report, and move it to the front of the workbook.

Shortcuts in this lesson

  • ↑/↓/←/→ Move one cell
  • Ctrl+↑/↓/←/→ Jump to the edge of the data
  • Ctrl+Home Go to A1
  • Ctrl+End Go to the last used cell
  • Ctrl+PageUp/PageDown Previous / next worksheet
  • Alt H O R Rename sheet
  • Alt H I S Insert sheet
  • Alt H D S Delete sheet
  • Alt H O M Move or copy sheet
