Lesson 1: The workbook the managers sent

Foundations · Open and set up · easy · Free

undefined

What you will do

  1. The arrow keys move one cell per press. Ctrl and an arrow jumps to the edge of the data in one press (down, up, left or right), and the Name Box, left of the formula bar, shows where you landed. Walk down the dates with ↓ five times, then jump the rest of the way with Ctrl+↓ until the Name Box reads A61.
  2. Ctrl+↑ jumps to the top of the data. Ctrl+Home takes you home to A1 from anywhere on the sheet, which is the one to remember when you get lost in a big file. Come back up the same way: ↑ five times, then Ctrl+↑ to A1.
  3. The same jump works sideways. Left, right, up, down: four keys that replace almost all of your scrolling. Across the headers: Ctrl+→ to the last column, F1, then Ctrl+← back to A1.
  4. A selection is the set of cells a command will act on, the highlighted block. Hold Shift with any arrow and the selection grows a cell at a time; hold Ctrl and Shift and it grows to the edge of the data. Two presses select a table of any size. Select the whole date column from A1 in one Ctrl+Shift+↓, then widen the selection to the whole table with Ctrl+Shift+→: A1:F61.
  5. A workbook is the file; the tabs along the bottom are its sheets, and Ctrl+PgDn and Ctrl+PgUp walk them. The grid shows a result; the formula bar shows where it came from, and that’s the one a reviewer reads. Walk the tabs to Costs with Ctrl+PgDn and land on the Domain total in E4, where the formula bar shows =B4+C4+D4.
  6. Rename Sheet is Home › Format › Rename (Alt, H, O, R): type the new name and press Enter. Every formula that points at this sheet will carry the name you type now, so name it once and name it right. Rename the Sheet2 tab to Inputs.
  7. Delete Sheet (Alt, H, D, S) removes the active sheet; Excel asks first because it can’t be undone. Stale data left in a file gets read as if it were current, so it comes out. Nothing warns you when other tabs read the one you delete (their formulas turn to #REF!), so on a live model you search the workbook for the tab’s name first (3.6.3). Delete the Old wk37 tab, since it’s last week’s export and the live numbers are on Raw.
  8. Shift+F11 inserts a sheet, Alt, H, O, R names it, and Move or Copy Sheet (Alt, H, O, M) moves it: ↑ ↓ pick where it sits, Enter confirms. The output page goes first: tabs run the way a reader reads. Add a new sheet for the report, name it Report, and move it to the front of the workbook.

Shortcuts in this lesson

  • ↑/↓/←/→ Move one cell
  • Ctrl+↑/↓/←/→ Jump to the edge of the data
  • Ctrl+Home Go to A1
  • Ctrl+End Go to the last used cell
  • Ctrl+PageUp/PageDown Previous / next worksheet
  • Shift+↑/↓/←/→ Extend the selection one cell
  • Ctrl+Shift+↑/↓/←/→ Extend to the edge of the data
  • Alt H O R Rename sheet
  • Alt H I S Insert sheet
  • Alt H D S Delete sheet
  • Alt H O M Move or copy sheet
