Lesson 22: Numbers a banker can read

Foundations · Format · medium · Free

undefined

What you will do

  1. A number format changes how a value shows, not the value itself. Format Cells (Ctrl+1) opens with the keyboard on its row of tabs, where N is the Number tab; Tab steps into the Category list, and there N picks Number with its three settings: Decimal places, Use 1000 Separator and Negative numbers. Set 0, tick the separator and pick (1,234): that’s the desk number format, which Excel stores as the code #,##0_);(#,##0), and every dollar figure and every check in this course carries it. Select the wash counts C5:C11, Total included, and set the desk number format in Ctrl+1: Number, no decimals, the separator, (1,234).
  2. F4 repeats your last action, and a whole trip through Format Cells counts as one action, so the desk number format lands on the new block in one press. It shows a negative in parentheses, which is the convention: never a leading minus on a page. Alt, H, 9 takes a decimal off and Alt, H, 0 puts one on, for the lines that need them. Revenue, Wash cost and Gross profit D5:F11 take the same format: select them and press F4, so a loss would read in parentheses.
  3. The currency sign sits on the first row and the total row of a money column, and nowhere in between. A page full of $ is noise. In Ctrl+1 the same steps reach Currency (N, Tab, then C) with decimals at 0 and ($1,234) under Negative numbers, so a loss on a $ row reads in parentheses like the rows between. The $ goes on a money column’s first and total rows only: make D5:F5, D11:F11 and Prior week’s I5 currency with no decimals in Ctrl+1.
  4. Format the whole span, empty cells included, so a figure typed later comes out right. The $ stays on I5 above; the body takes the desk number format, and once another action has taken F4’s place, Paste Special Formats (1.3.4) from a cell that carries it is the repeat. Prior week rev I6:I10 gets the desk number format by Paste Formats from D6, Cedar Park’s empty I9 included, while I5 keeps the column’s $.
  5. Ctrl+Shift+4 is currency with two decimals in one press, right for a per-unit figure like a ticket price. Selecting from the bottom with Ctrl+Shift+↑ runs to the header; Shift+↓ steps back off it. Avg ticket ($/wash) shows cents: select G5:G11 from the bottom, Ctrl+Shift+↑ then Shift+↓ off the header, then currency, Ctrl+Shift+4.
  6. Ctrl+Shift+5 is percent with no decimals; Alt, H, 0 adds one. One decimal on a percentage is the convention: 41.2%, not 41% and not 41.23%. Margin % H5:H11 reads as a percentage to one decimal: select it the same way, Ctrl+Shift+5 for percent, then Alt, H, 0 for the decimal.
  7. Ctrl+Shift+1 applies Number with a thousands separator and two decimals in one press, and Alt, H, 9 takes a decimal off. It shows a negative with a minus sign, so keep it for counts that can’t go below zero, like washes; dollar lines and checks take the desk number format. Format the block before the figures arrive and every link that lands there comes out right. The daily table B17:G21 will hold thirty wash counts: format the whole block at once with Ctrl+Shift+1, then Alt, H, 9 twice.
  8. A per-unit input keeps the decimals it’s quoted to. $1.50, not $2 and not $1.5000. On Inputs, the cost per wash B4 is quoted to the cent: currency with two decimals, Ctrl+Shift+4.
  9. The format rides on the cell; the value moves underneath it. Change an input, and the total updates in the format you set. Does it tie? Change Cedar Park’s washes in C9 to 300 and watch the Total in C11 answer, thousands separator and all.
