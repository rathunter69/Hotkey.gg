Lesson 45: The four-section format

Formatting and presentation · Custom number formats · medium · Paid

undefined

What you will do

  1. Format Cells › Custom, Ctrl+1 then U, takes a code of up to four sections separated by semicolons, positive;negative;zero;text: _) leaves a space the width of a parenthesis. Select the figure block B5:P18 and give it the house plain code: Ctrl+1, U, then #,##0_);(#,##0);-_) and Enter.
  2. The first row B5:P5 carries the $: back to B5 with Home and →, select the line and give it $#,##0_);($#,##0);-_) the same way.
  3. Total revenue B8:P8 and Gross profit B10:P10 wear the same $ code: select each line in turn and press F4 to repeat it.
  4. Gross margin % B11:P11 gets the percent code 0.0%_);(0.0%);-_), one decimal and the same dash for a zero.
  5. Total operating costs and EBITDA, B16:P17, are totals: jump to the foot, up two, select both lines and type the $ code again.
  6. EBITDA margin % B18:P18 gets the percent code too, so both margins read alike.
  7. Does it tie? Watch January’s maintenance in E13 go to 0 and read as a dash, and Total operating costs in E16 answer.
