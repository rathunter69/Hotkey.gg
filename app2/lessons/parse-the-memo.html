Lesson 99: FIND, SEARCH and SUBSTITUTE: parse the memo

Formulas and functions · Text · hard · Paid

undefined

What you will do

  1. FIND(find_text, within_text) returns the position of the first match, counting from 1, so FIND("@",F5) reads 8 in “Wash B @ AUS-AIR”. It is case-sensitive, and it returns #VALUE! when the text is not there. On Transactions, select U5:U94, type =FIND("@",F5) and press Ctrl+Enter: the position of the @ in every memo.
  2. MID needs a start, and FIND gives it one: the code starts two characters after the @, so MID(F5,FIND("@",F5)+2,7) cuts it out wherever the @ falls. Nest FIND inside MID and the position is never typed. The site from the memo in V5:V94: =MID(F5,FIND("@",F5)+2,7) with Ctrl+Enter, then compare it with column B.
  3. The channel has no fixed length, so cut from one FIND to another: start one past the "(", and take as many characters as lie between the brackets. FIND and SEARCH also take a third argument, where to start looking, which finds the second space as easily as the first. The channel in W5:W94: =MID(F5,FIND("(",F5)+1,FIND(")",F5)-FIND("(",F5)-1) with Ctrl+Enter.
  4. SEARCH works like FIND but ignores case, so SEARCH("wash ",F37) finds “Wash ” and “wash ” alike. UPPER capitalizes every letter, so the package reads one way whatever the terminal typed. Row 37’s memo came through as “Wash d”: read its package in X37, case-blind, with =UPPER(MID(F37,SEARCH("wash ",F37)+5,1)).
  5. Now the package for every row in X5:X94: =UPPER(MID(F5,SEARCH("wash ",F5)+5,1)) with Ctrl+Enter.
  6. SUBSTITUTE(text, old_text, new_text) swaps every match for the new text, and a fourth argument changes only the nth. REPLACE swaps by position instead of by content. Parse into helper columns and keep the raw memo: it is the audit trail. Row 34 is a kiosk wash: drop the tag in Y34 with =SUBSTITUTE(F34," (kiosk)","").
  7. Every memo without the kiosk tag in Y5:Y94: =SUBSTITUTE(F5," (kiosk)","") with Ctrl+Enter; a memo with no tag passes through unchanged.
  8. Does it tie? Watch the memo in F5 change its channel to (app), and the channel in W5 follow it.
