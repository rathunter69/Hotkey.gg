Lesson 123: Challenge: a broken lookup summary rebuilt

Data and lookups · Lookups · hard · Paid

Another cluster’s site block reads its list through five broken lookups: one without FALSE, one counting a moved column, one keyed on the wrong column, one OFFSET, one that errors silently. Rebuild every line with INDEX/MATCH or XLOOKUP so it ties to Lists.

What you will do

  1. Restore exact match on the site names in Summary C5:C10.
  2. Fix capacity in D5:D10 so no column number is counted.
  3. Key hours open in E5:E10 on the code in column B, not the name.
  4. Rewrite daily site costs in F5:F10 without OFFSET.
  5. Key the opened dates in G5:G10 on the code, and make a miss say Not listed instead of a blank.
