Lesson 5: Color-code the workbook

Foundations · Open and set up · medium · Free

undefined

What you will do

  1. Every typed number in the file lives on Inputs, so it’s the sheet a reviewer opens first, and the sheet where color coding matters most. Inputs is the sheet where the typed numbers live: go there first.
  2. The formula bar shows what a cell holds, and a number with no = in front of it is a hardcode, meaning somebody typed it, so it goes blue. Font Color lives on the Home tab: Alt, H, F, C opens the palette, the arrow keys move across the swatches and Enter picks one. Land on B4, read 1.50 typed in the formula bar, and color it blue.
  3. To select across cells, hold Shift and press an arrow: from B5, Shift+↓ takes B6 too, and the Name Box reads B5:B6. A format applied to a selection lands on every cell in it, so select first, then Font Color once. B5 and B6 are typed too: select both and color them blue in one go.
  4. A reference with a sheet name and an exclamation mark points at another sheet, and links are green, so a reader knows which figures come from elsewhere in the file. Red is for a link to another file, which you’ll avoid. The team never links workbooks. B12 holds =Raw!I13, a link to another sheet: color it green.
  5. Formulas are black. Automatic is the default font color, and it’s the one every calculated cell should have. Nothing typed, nothing to change. B10 holds =B5*B6, a formula, so it stays black, but set its font color to Automatic if it isn’t.
  6. Read each cell in the formula bar before you color it: no =, blue; =, black; a sheet name and !, green. The card ticks each cell as it turns the right color. Now do the rest of the block, B7:B14, where three more typed numbers, two formulas and one link each need the right color.
  7. F2 puts a cell into edit mode: the caret appears at the end of the entry and, for a formula, each reference lights up in color on the sheet. Enter leaves edit mode and keeps your changes; Esc leaves it and throws them away. Typing on a cell without F2 replaces the whole entry. Read the block back: press F2 on B10, watch its inputs light up on the sheet, then leave with Esc.
  8. A wrong color is worse than no color: a reviewer would change B15 thinking it was an input. Ctrl+1 opens Format Cells, the dialog behind all of this: its Font tab has the same color list as the Ribbon route, with Automatic first. B15 is blue but holds a formula, =B10/B6: set its font color back to Automatic.
