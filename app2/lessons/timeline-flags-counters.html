Lesson 164: The timeline row: flags and counters

Finance and Accounting · Model setup and efficiencies · medium · Paid

Every sheet in the model shares one timeline: FY24 to FY31 across the same columns, built from one date on Inputs (2.6.2), with the A/E flags underneath (2.1.4). This time the flags do work: a projection flag (1 in a projected year, 0 in a historical one, FY26 included) lets one formula read the actual where there is one and calculate where there isn’t, and a counter drives growth and ramps. Build the row once on Inputs and link it to every sheet. The key is EOMONTH.

What you will do

  1. The model is annual because it values the business, and it projects five years because fewer gives too little to value and more is hard to defend. One date is typed; every other year end counts on from it. On Inputs, type 12/31/2024 in C4, then =EOMONTH(C4,12) in D4 filled right to J4 with Ctrl+R.
  2. FY26 is the estimate for the year still running (2.1.4): its accounts aren’t closed, so it reads E like the forecast. The A/E row: A and A in C5:D5, then E across E5:J5 in one entry with Ctrl+Enter.
  3. The last year with figures from the accountants is an input, typed once in blue and named, so the flag reads a stated date and not a column. Type 12/31/2026 in C11 and name it LastHistorical with Alt, M, M, D.
  4. Best practice: a formula that reads the flag, =IF(flag=0, actual, calculation), lets one row carry history and forecast with no seam. The projection flag in C6, =IF(C$4>LastHistorical,1,0), filled to J6: 0 for FY24 to FY26, 1 after.
  5. Counters: 1 in C7 and =C7+1 across D7:J7, then =IF(C6=1,MAX(B8,0)+1,0) across C8:J8, which starts at 1 in FY27.
  6. The desk’s other counter, =COLUMNS($C4:C4), reads 1 in the first period and one more with every column it fills across, with no first cell to break and no typed offset. Insert a column in front and it still counts from 1, where =COLUMN()-2 would not. Fill =COLUMNS($C4:C4) across C9:J9, and =C9-C7 across C10:J10, which reads zero.
  7. Best practice: the same year sits in the same column on every sheet, FY26 in column E everywhere, so a link across sheets never needs a MATCH and a reviewer never counts columns. Group IS to DCF with Ctrl+Shift+PgDn, and link row 4 once: =Inputs!C4 in C4, filled right to J4.
  8. Does it tie? Watch FY24’s year end on Inputs move back a year, and every header on IS roll with it.
