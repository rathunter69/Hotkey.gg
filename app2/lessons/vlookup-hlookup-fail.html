Lesson 116: VLOOKUP and HLOOKUP, and how they fail

Data and Lookups · Lookups · medium · Paid

VLOOKUP(key, table, column number, FALSE) looks down the first column for the key and returns the nth column; HLOOKUP does the same across a row. It fails three ways, and each one looks like a number: leave off FALSE and an unsorted list returns a near key, insert a column and the counted column moves, look up by anything but the first column and it reads #N/A. Fill the site block on Summary, then break it each way and read what it says. The key is VLOOKUP.

What you will do

  1. Fill the site names into Summary C5:C10 with =VLOOKUP(B5,Lists!$B$5:$H$10,2,FALSE) and Ctrl+Enter.
  2. Capacity is column 5 of the same table: fill D5:D10 the same way.
  3. Leave off FALSE and VLOOKUP assumes the first column is sorted, then returns the nearest key at or below the one you asked for. The site codes aren’t sorted, so the answer is a wrong site, said with confidence. Fail one: in E8, leave FALSE off, =VLOOKUP(B8,Lists!$B$5:$H$10,2), and read Cedar Park come back for South Lamar.
  4. VLOOKUP only looks down the table’s first column, so a key from any other column finds nothing. #N/A is Excel saying the key isn’t there, and it is the error to read first on any lookup. Fail three: retype E8 keyed on the name, =VLOOKUP(C8,Lists!$B$5:$H$10,5,FALSE), and read #N/A.
  5. Clear E8 with Delete; the two failures have made their point.
  6. A column number is counted once, when the formula is written. Insert a column inside the table and the table widens, but 5 still means the fifth column, which is now the new blank one. Fail two: insert a column on Lists at F, before capacity, read D5 drop to 0, then press Ctrl+Z.
  7. HLOOKUP(key, table, row, FALSE) looks across the table’s top row for the key and returns the row you count down to. The cube’s header row holds the week labels, so Domain, the first site, is row 2. In I14, read Domain’s washes for the week in H14 with =HLOOKUP(H14,$C$14:$E$20,2,FALSE).
  8. Does it tie? Watch Domain’s capacity on Lists move to 130 and D5 follow it.
