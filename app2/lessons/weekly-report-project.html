Lesson 72: Project: the weekly report

Foundations · Project and assessment · medium · Free

The Raw sheet holds an export; the Report sheet is blank. Build the weekly report on it end to end: title, headers, live links to the raw numbers, totals, formats, borders and a frozen header. This is the whole chapter on one page — take your time, everything is graded on the end state.

What you will do

  1. Type Weekly Sales Report into A1 and make it bold.
  2. Build the header row: Day in A2, Sales in B2, Units in C2, all bold.
  3. Link the day names: enter =Raw!A3 in A3 and fill it down to A7.
  4. Link the figures: enter =Raw!B3 in B3 and =Raw!C3 in C3, then fill B3:C7 down.
  5. Type Total into A8, then select B3:C8 and AutoSum both columns at once.
  6. Give the Sales column B3:B8 the Number format from Ctrl+1.
  7. Centre the title across A1:C1 with Ctrl+1, A.
  8. Rule the table: All Borders on A2:C8, then a thick outside ring.
  9. Fill the header row A2:C2 gray and AutoFit columns A to C.
  10. Freeze the top row so the title stays put when the report grows.
