Lesson 49: Conditional codes and hidden zeros

Formatting and presentation · Custom number formats · medium · Paid

undefined

What you will do

  1. A section can open with a color or a condition: [Red] paints that section’s values red, and [<1000] uses a section only for values under 1,000. The checks C39:C40 read zero when the page ties: give them 0_);[Red](0);-_) so a negative check paints itself red.
  2. Washes in C34:E34 are thousands: give them [<1000]0;#,##0 so a small count and a large one each read right.
  3. An empty section shows nothing, so ;;; hides every kind of value while the cell still holds it for any formula that reads it. Hide the flags C5:E5 with the code ;;; so the cells keep their A and E but the page stops showing them.
  4. On Inputs, the switch in B12 holds a 1: give it On;;Off, with the negative section left empty, so it reads On and still multiplies.
  5. General is the format with no format: General at the top of Ctrl+1’s list returns a cell to showing its value as typed. Back on the P&L, set the flags C5:E5 to General, the top of Ctrl+1’s list, and they show again.
  6. Does it catch it? Watch total revenue in C10 typed over as 32000, and the check in C39 leave zero and turn red.
