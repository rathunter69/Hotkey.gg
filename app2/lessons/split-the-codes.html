Lesson 59: LEN, LEFT, RIGHT and MID: split the codes

Formulas and functions · Text · medium · Paid

undefined

What you will do

  1. LEFT(text, n) takes n characters from the start of a text and RIGHT(text, n) takes n from the end; MID(text, start, n) takes n from a position, so MID(F5,6,1) is the package letter in “Wash D @ …”. The cluster is the first three letters of the code. On Transactions, select S5:S94, type =LEFT(B5,3) and press Ctrl+Enter: the cluster of every wash.
  2. The site from the other end in T5:T94: =RIGHT(B5,3) with Ctrl+Enter, then read T25, where a trailing space leaves "OM ".
  3. LEN(text) counts the characters, spaces included, so every clean code reads 7 and a code with a hidden space reads 8. No eye can see a trailing space; LEN can. Count every code’s characters in R5:R94: =LEN(B5) with Ctrl+Enter, and two rows read 8.
  4. COUNTIF on Summary reads the raw code, and "AUS-DOM " is not AUS-DOM to a criteria, so the two rows LEN found are two washes the site counts have missed from the start. Fix the data at its source and every formula that reads it agrees. Retype the two codes where LEN reads 8 without the space: AUS-DOM in B25 and AUS-MUE in B66.
  5. The next export may send the space again. TRIM (2.6.4) inside the RIGHT strips it before RIGHT counts, so RIGHT(TRIM(B5),3) reads DOM whatever the terminal sends. Make the site column survive the next dirty export: rewrite T5:T94 as =RIGHT(TRIM(B5),3) with Ctrl+Enter.
  6. Read the checks on Summary in C80:C83: the two count checks are back to zero, and the reconciliation now reads (2).
  7. Does it tie? Watch the code in B5 change to SAT-ALA, and its length, cluster and site in R5:T5 split it again.
