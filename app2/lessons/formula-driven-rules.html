Lesson 64: Formula-driven rules: a check that isn’t zero turns red

Formatting and presentation · Conditional formatting · medium · Paid

The built-in rules ask about the cell’s own value; a formula rule can ask anything. The checks row should turn red when a check isn’t zero, and a whole row can highlight when the flag at its left says so. Write the rule once with the right anchors and it applies across the range like any formula. The key is Alt H L N.

What you will do

  1. Alt, H, L, N opens a new rule that uses a formula: the cell is painted wherever the formula is TRUE. =C39<>0 reads “C39 is not zero”, so a check paints itself the moment two figures disagree. Select the checks C39:C40 and add a formula rule, =C39<>0, with the Light Red Fill.
  2. A formula rule is written for the top-left cell of the selection and read in every cell as if it had been filled. $A7 locks the column, so every cell of a row looks at its own flag in A, and the row stays free to move down. Select the revenue lines B7:E9 and add =$A7="x" with the Yellow Fill, so the row flagged x in A8 lights up.
  3. Type x in A9 and watch B9:E9 light up too: the rule follows each row.
  4. Clear the flags in A8:A9 with Delete, so the page keeps no x and no yellow.
  5. Open Manage Rules with Alt, H, L, R and read the four rules, the newest on top.
  6. Close Manage Rules with Enter.
  7. Does it tie? Watch total revenue in C10 typed over as 32000, and the check in C39 leave zero and turn red.
