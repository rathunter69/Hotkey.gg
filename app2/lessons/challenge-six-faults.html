Lesson 61: Challenge: six faults in a summary

Formulas · Auditing · hard · Paid

undefined

What you will do

  1. Airport’s SUMIF in D70 stops a row short of the export: make the ranges in D66:D71 run to row 94.
  2. One site’s retail revenue in D66:D71 is a typed number: give every row the same live SUMIF.
  3. One wash count in C66:C71 is a number stored as text: link every row to its site count again.
  4. C73 reads last year’s databook through an external link: replace it with the 710 it fetched, typed blue.
  5. One new-price formula in E66:E71 multiplies by a typed 1.05: point it at the uplift input in C75.
  6. The loan check in C84 is a typed 0: link it to the schedule’s check on Loans, and the flag in C2 reads OK.
