Lesson 50: Challenge: the number-format set

Formatting and presentation · Custom number formats · medium · Paid

A fresh cluster export with a monthly block, still in the built-in formats. Apply the set: the four-section codes on dollars and percents, FY codes, mmm-yy on the months, units on the summary and red on the check.

What you will do

  1. Give the P&L lines C7:E24 the plain code #,##0_);(#,##0);-_) in the Custom box.
  2. Give the actual years C4:D4 the code "FY"yy"A" and the estimate E4 the code "FY"yy"E".
  3. On Inputs, show FY26E revenue in B15 in millions with the code #,##0.0,"m".
  4. On Monthly, show the month ends in C4:N4 as dates with Ctrl+1, Date, mmm-yy.
  5. On the P&L, give the check in C39 the code 0_);[Red](0);-_) so a miss turns red.
  6. Put the $ code $#,##0_);($#,##0);-_) on C7:E7, then on total revenue C10:E10 and EBITDA C24:E24 with F4.
  7. Give the margins block C27:F30 the percent code 0.0%_);(0.0%);-_).
