Lesson 49: Challenge: the house number-format set

Formatting and presentation · Custom number formats · medium · Paid

undefined

What you will do

  1. Select the figure block B5:D18 and give it the house plain code #,##0_);(#,##0);-_) in the Custom box.
  2. The first row and the totals in rows 8 and 10 wear the $ code $#,##0_);($#,##0);-_): type it on B5:D5 and repeat it with F4.
  3. Gross margin % B11:D11 and EBITDA margin % B18:D18 wear the percent code 0.0%_);(0.0%);-_), typed once and repeated with F4.
  4. Total operating costs and EBITDA, B16:D17, are totals: two rows up, select both lines and type the $ code again.
  5. Revenue per site B21:D21 reads in thousands: give it $#,##0,k_);($#,##0,k);-_) so the k lives in the format.
  6. On Inputs the leverage B10:D10 is text, 2.9x: retype it as 2.9, 2.4 and 1.9 with Tab, then give the line the code 0.0x.
  7. The tariff increase B8:D8 is quoted in basis points: two rows up, give it the code 0 bps.
