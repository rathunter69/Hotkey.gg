Lesson 31: Read the error, follow the trail

Foundations · Formulas · hard · Free

undefined

What you will do

  1. Each error code is a message: #REF! a deleted reference, #NAME? a name Excel does not know, #VALUE! text where a number belongs, #N/A a lookup that found nothing. On Costs, Mueller’s total E5 says #REF!, a reference that was deleted: replace the dead tail with a pointer to D5 so it reads =B5+C5+D5.
  2. E6 says #NAME?: SUMM is not a function Excel knows, so edit the name in place to SUM and the total reads 2,580 again.
  3. E7 says #VALUE!: Ctrl+[ lands on B7, and along that row D7 says tbc where the flat 260 network fee belongs: fill it down from D6.
  4. Airport’s E8 says #N/A and holds nothing worth keeping: select E5:E8, press F2 on E5, and Ctrl+Enter writes its formula into all four rows.
  5. B10 now says #DIV/0!, a division by nothing: Ctrl+[ jumps to E9, Ctrl+] back, and it divides by the empty B12, so edit it to =E9/B11.
  6. B11 is a link to the Report: press Ctrl+[ on it and the trail crosses sheets to Report’s C11, the kWh the cost is spread over.
  7. Back on Costs, E5:E8 are formulas, not inputs, and must read black like E4: copy E4 and paste its format only onto them with Paste Formats.
  8. Does it tie? Watch Domain’s lease in B4 change to 2,500 and the cost per kWh in B10 answer through the Total.
