Lesson 11: Challenge: find and mark

Foundations · Move and select · medium · Free

A fresh feed from another cluster came through untidy, and Revenue is now a formula with stray typed numbers hiding in it. Select each part of the feed and fix it as you go, then mark every typed number in the Revenue column blue.

What you will do

  1. On Raw, select the figure headers C1:F1 and right-align them over their numbers.
  2. Select the whole header row and give it some air: row 1 at height 20.
  3. This cluster’s site names are cut off in column B: select the column and AutoFit it.
  4. Select the Revenue figures E2:E60 edge to edge, pick out the constants with Go To Special and color them blue.
