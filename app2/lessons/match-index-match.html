Lesson 117: MATCH, then INDEX/MATCH

Data and lookups · Lookups · medium · Paid

MATCH answers one question: which row is this key on. INDEX answers another: what is in the nth row of this column. Together they do what VLOOKUP does without its faults, because the key can sit in any column, the return column is pointed at rather than counted, and an inserted column changes nothing. It is two functions instead of one, and it is the lookup the standard uses, so rebuild the site block with it. The key is MATCH.

What you will do

  1. MATCH(key, range, 0) returns where the key sits in a one-column range: AUS-DOM is 1 in Lists!$B$5:$B$10, AUS-CED is 6. The 0 asks for an exact match, the same job FALSE does in VLOOKUP. Find each code’s row on Lists: fill Summary E5:E10 with =MATCH(B5,Lists!$B$5:$B$10,0).
  2. INDEX(range, n) returns the nth cell of a range. Give it the name column and the row MATCH found, and it brings back the name; give it another column and it brings back that instead. Bring back each name in F5:F10 with =INDEX(Lists!$C$5:$C$10,E5), the row MATCH found.
  3. Put the MATCH inside the INDEX and the lookup is one cell: point INDEX at the capacity column, and nothing is counted. This is INDEX/MATCH, the lookup the standard uses. Capacity with nothing counted: fill G5:G10 with =INDEX(Lists!$F$5:$F$10,MATCH(B5,Lists!$B$5:$B$10,0)).
  4. An inserted column moves Lists!$F$5:$F$10 to G with it, so INDEX/MATCH still points at capacity, while the VLOOKUP in D5 still counts to 5. Tip from the desk: inherited models often write VLOOKUP(B5,Lists!$B$5:$H$10,MATCH("Capacity (cars an hour)",Lists!$B$4:$H$4,0),FALSE), which cures the count but still needs the key in the first column. Insert a column on Lists at F again, read G5 hold at Domain’s capacity while D5 drops, then press Ctrl+Z.
  5. The key can sit in any column: MATCH the name in the name column and INDEX the code column, right to left, which VLOOKUP cannot do. Best practice: INDEX/MATCH for anything that lives longer than a week, VLOOKUP for a one-off you will delete. Look up each code from its name in H5:H10: INDEX on the code column, MATCH on the name in C5.
  6. Does it tie? Watch Domain’s capacity on Lists move to 130 and G5 answer.
