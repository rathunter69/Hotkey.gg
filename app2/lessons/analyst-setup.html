Lesson 3: Set Excel up like an analyst

Foundations · Open and set up · medium · Free

undefined

What you will do

  1. Calculation is Automatic here; F9, Calculate Now, is the key you live on when a big model goes Manual. Press F9 once — on Automatic it is instant, and your hands should know it.
  2. Alt, F, T opens Excel Options; on the Formulas page, I enables iterative calculation, which circular models need. Open Excel Options and enable iterative calculation.
  3. Q opens the Quick Access Toolbar page: ↑ ↓ pick a command, A adds it, Enter is OK. Add Font Color to the Quick Access Toolbar.
  4. Add Fill Color the same way.
  5. Add Borders.
  6. Add Decrease Decimal, the last of the four.
  7. Alt alone numbers the toolbar 1–9; Alt then the number runs that command from anywhere. Run one from the keyboard: Alt, then 2 — Undo, straight off the toolbar.
