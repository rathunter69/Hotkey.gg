Lesson 46: Units in the format

Formatting and presentation · Custom number formats · medium · Paid

undefined

What you will do

  1. A comma after the last digit placeholder divides by a thousand, and a unit rides along in quotes: the Custom box turns $#,##0,k into $#,##0,"k" for you. Revenue per site B21:P21 reads better in thousands: select the line and give it $#,##0,k_);($#,##0,k);-_) in the Custom box.
  2. On Inputs the leverage B10:D10 was typed as text, 2.9x: Go To Inputs!B10 and retype the three figures as 2.9, 2.4 and 1.9 with Tab.
  3. Now give B10:D10 the multiple code 0.0x, so the x is in the format and the numbers stay numbers.
  4. The tariff increase B8:D8 is quoted in basis points: two rows up, select it and give it the code 0 bps.
  5. On Monthly, kWh sold B6:M6 runs to seven digits: Go To Monthly!B6, select the line and give it #,##0,k.
  6. kWh per session B8:M8 straddles 20: two rows down, give it 0.0 so every month shows one decimal.
  7. Is it a number? Watch FY24A’s leverage in B10 change to 3.5 and read 3.5x: the x lives in the format, not the cell.
