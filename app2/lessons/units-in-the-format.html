Lesson 47: Units in the format: k, m, x, bps

Formatting and presentation · Custom number formats · medium · Paid

The figures are in thousands, and a page that says so once at the top is fine, until a figure travels alone onto a slide or into an email. The unit can live in the format: a literal "k" after the number, "m" with a comma that divides by a thousand, "x" for a multiple, "bps" for a spread. The value stays a plain number that formulas can read; only the display carries the unit. The key is Ctrl+1.

What you will do

  1. A comma after the last digit divides the display by a thousand and text in quotes rides along, so 50000 thousand reads 50.0m while the cell still holds 50000. On Inputs, show FY26E revenue in B15 in millions: give it #,##0.0,"m" in the Custom box.
  2. Revenue per site in B16 is already in thousands: give it #,##0k so it reads 1,250k.
  3. The multiple in B13 was typed as text, 12.0x, and no formula can use it: retype it as the number 12.
  4. Give B13 the code 0.0x, so the x lives in the format and the 12 stays a number.
  5. The margin change in B14 is a spread: give it the code 0 bps.
  6. On the P&L, give revenue per wash C35:E35 the code $0.00" /wash" so the unit travels with it.
  7. Is it a number? Watch the multiple in Inputs B13 change to 13.5 and read 13.5x: the x lives in the format.
