Lesson 8: Selecting a range

Foundations · Selecting · easy · Free

Formatting, copying and formulas all start with a selection. In this lesson you select ranges of the Weekly Sales Report from the keyboard: a column of figures, a whole row and the entire block. Selecting without the mouse is the habit that makes everything after it quick.

What you will do

  1. A range is a block of cells, and Shift+Arrow extends the selection one cell at a time from the active cell. Select the Sales figures B3:B7.
  2. Ctrl+Shift+Arrow extends the selection to the edge of the data in one press. Select the Units figures C3:C7 with a single press.
  3. Shift+Space selects the whole row and Ctrl+Space the whole column. Select the whole header row 2.
  4. Ctrl+A selects the current region: the whole block of data around the active cell. Select the whole report, A1:C7.

Shortcuts in this lesson

  • Shift+↑/↓/←/→ Extend the selection one cell
  • Ctrl+Shift+↑/↓/←/→ Extend to the edge of the data
  • Shift+Space Select the entire row
  • Ctrl+Space Select the entire column
  • Ctrl+A Select the current region, then the whole sheet
