Lesson 52: Reading formula errors

Foundations · Basic formulas · hard · Free

An error code is a message, not a mystery: #NAME? blames the function, #DIV/0! the divisor, #VALUE! the types, #REF! a reference that no longer exists. In this lesson the Checks column shows all four and you fix each one. Reading errors calmly is what separates fixing from flailing.

What you will do

  1. #DIV/0!, #NAME?, #VALUE! and #REF! each say what broke: the input, the name, the type, the reference. D3 shows #NAME? — retype the total with the function spelt SUM.
  2. D4 shows #DIV/0! because Tuesday’s units are missing — type 31 into C4.
  3. D5 shows #VALUE! — replace it with a formula that adds B5 and C5, two real numbers.
  4. D6 shows #REF! — the cell it pointed at was deleted long ago; repoint it to B6 times 2.
