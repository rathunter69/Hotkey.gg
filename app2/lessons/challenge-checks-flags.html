Lesson 67: Challenge: the checks flags on a model

Formatting and presentation · Conditional formatting · medium · Paid

A cluster model with a checks block and no rules on it, plus three stray rules someone left. Make the check flag red, light the flagged row, strip the decoration and tidy the list.

What you will do

  1. Give the check in C39 a formula rule, =C39<>0, with the Light Red Fill.
  2. Light the revenue row flagged x in column A: a rule on B7:E9 that reads =$A7="x", with the Yellow Fill.
  3. Take the data bars off C10:E10 and the color scale off C13:E19.
  4. Delete the stray Greater Than 1,000 rule on C7:E9, so only the flagged row lights.
  5. In Manage Rules (Alt, H, L, R), put the checks rule on top with U and tick Stop If True with S.
