## Traps

- `validateLesson` rejects a first goal already satisfied by the starting state; with module states the starting state is the previous lesson's `after`, so check the first goal against it, not against `S0`.
- Goals latch: every format or value a goal leaves must be in `after` (the diff test catches omissions, which is the point).
- Logged labels are exact (see C-chapter1.md "Traps"); new ones: `'Alt+Shift+→'`, `'Alt+Shift+←'`, `'Ctrl+`'`.
- `Ctrl+Shift+↓` from a cell with a blank below jumps to the next non-blank, as in Excel; author selections on contiguous blocks or use Shift+↓ ×n (≤3) or Ctrl+Shift+End.
- Never grade a formula by regex; `liveness` + value, and `noLiteralInFormula` reads the parsed token list, not the string.
- A challenge grader must read the sheet (sums computed from cells), never a constant — the seed changes the figures.
- Grouped ≠ hidden: `noHidden` must pass on a collapsed group.
- The workspace height change affects the drill workspace too (`drill-run.js` shares the stage); check the old trainer layout still matches the reference.
- Old build at repo root is reference only; the isolation check fails any import from outside `app2/`. Do not touch `supabase/**`.
