Last updated 2026-10-01. Sequence, status and open decisions, for the build sessions and for Wolf. One plan: this file is docs/REBUILD_PLAN.md in the repo and claude/rebuild-direction.md in the claude.ai project, and the two are kept identical. ## 1. Direction
- Learning-first Excel platform: read -> guided -> solo -> timed. Speed, boards and competition are the layer learners graduate into.
- Six chapters; Chapter 1 (Foundations) is free, the rest paid: Foundations, Formatting, Formulas, Data and Lookups, Finance and Accounting, Valuation. One case runs through all six: Clearcoat Express, forty express car washes in Texas, being sold to private equity (Project Rinse); the learner works on its finance team. Anything in the code still named Voltline or Project Volt is the earlier case and is re-skinned in run R1 (section 2a).
- The look follows screenplay 3.0 (approved 2026-10-01); of the old build only the Ribbon is kept as built. Every timed run uses one panel at the right of the sheet, and a lesson's task card sits beside its target.
- Existing user data is not preserved. New database, new schema.
- Developer: Claude Code sessions on branch `rebuild`, new code under `app2/`. The claude.ai project chat reviews branches, applies database migrations, and owns security, legal, launch and ops.
- Business: LLC formed; Mercury for banking and accounting. Payments: Stripe Embedded Checkout with Managed Payments (Stripe, through Link, is merchant of record and handles sales tax and VAT); subscriptions at $15 a month, students $9; sandbox only until Wolf says go. Brief: docs/phases/E-checkout.md.

## 1a. MVP definition (what the build sessions build before a full review)
The MVP is the **whole course built, with the paid chapters gated behind a manual flag**:
- All of Chapter 1 (Foundations), accounts, and the full game layer (drills, pars, PBs, the Daily, rapid-fire, boards, quests, XP, achievements, cosmetics, stats).
- Chapters 2–6 built from the chapter scripts (section 2a), locked behind a `paid` entitlement that Wolf grants by admin or redeem code. No checkout in the MVP.
- Desks, issuing the certificate (its progress page is R1b's), group codes, school flair and real checkout come after the MVP is reviewed (Phases F, E-checkout). Exception: the checkout plumbing is built in parallel on branch `payments` (1d), behind a flag that keeps it off hotkey.gg.
Wolf reviews by playing: each run ends on a preview, and his notes come back as a pass, not as a gate.
