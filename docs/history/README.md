# Historical records

This directory holds dated records that explain earlier decisions without competing with the
current queue or workflow.

| Record | What it preserves | Current entry point |
|---|---|---|
| [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) | Earlier session handoffs, rationale and dated status notes | [README.md](../../README.md), [CURRENT.md](../CURRENT.md), [DEVELOPMENT.md](../DEVELOPMENT.md) |

Archived material is evidence and context. It does not authorize a deployment, a catalog change,
or the execution of a historical queue. The root `PROJECT_CONTEXT.md` remains as a compatibility
page for existing links.
