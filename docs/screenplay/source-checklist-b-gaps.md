# hotkey.gg · Source checklist: Section B: gaps, fixes to our scripts, held items

*One of six files. claude/source-checklist.md is the index: it holds sections F and H and says where every section is. The checklist was one 553 KB file until 2026-10-01 and was split so every Claude surface can open it; nothing in it changed, and row ids (A rows, the B ids G### and F##, the D ids D##) are the same.*

## B. Gaps and proposals

Every gap candidate was judged against all six chapter scripts by two verifiers (Chapters 1–4 and 5–6), which read the scripts end to end. **Confirmed** means we do not teach it, it passes the relevance filter and it fits the budget. Default placement is the smallest edit inside an existing lesson; there are no new lessons. *Skip* says whether a generic Excel course would skip it (yes is the value proposition). Where there is a real choice, the recommendation comes first. Ids are used again in H.
