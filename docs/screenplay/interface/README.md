# The interface, drawn

The approved screens of the interface standard (screenplay section 3.0), rendered from the design canvas "hotkey.gg interface" on 2026-10-01. They show the intent. Section 3.0 is the standard: where a drawing and 3.0 differ, 3.0 wins, and nothing here needs matching to the pixel. Wolf adjusts the look in code once the content is in (3.0, "Build for change").

Every screen is drawn at 1440 by 900 unless its height is given. The two animated boards are shown as one frame; the canvas plays them.
