## 1. Schema — `app2/supabase/migrations/0001_accounts.sql`, `0002_attempts.sql`, `0003_events.sql`, `0004_rpcs.sql`
Every table: `enable row level security`; `revoke all on <table> from anon, authenticated`; grant only `select` where stated. No insert/update/delete grants to client roles anywhere. Every function: `security definer`, `set search_path = ''` (so **schema-qualify everything**: `public.profiles`, `auth.uid()`, `extensions.gen_random_uuid()`), `revoke execute … from public, anon, authenticated` then `grant execute … to authenticated` (RPCs only), first statement `if auth.uid() is null then raise exception 'not signed in'; end if;`. All timestamps `timestamptz`.

**`profiles`** (owner-only): `id uuid pk references auth.users on delete cascade`, `handle text not null check (handle ~ '^[A-Za-z0-9_]{3,20}$')` with `create unique index profiles_handle_lower on profiles (lower(handle))` (no citext: with an empty search_path citext operators are not found and comparisons silently become case-sensitive), `handle_changed_at`, `theme text`, `experience text check (experience in ('new','sometimes','daily'))`, `first_run_done bool default false`, `skipped_lessons text[] default '{}'`, `public_profile bool default true`, `show_school bool default false`, `xp int default 0`, `level int default 1`, `carried_guest_id uuid unique`, `carried_at`, `created_at default now()`. Policy `select using (id = auth.uid())`. `public.generate_handle()`: adjective + noun + two digits from two small inline arrays, loop until no `lower()` match. Trigger `after insert on auth.users` inserts the profile.

**`profiles_public`** (a table, not a view): `id uuid pk`, `handle text`, `level int`, `rank_tier text null`, `featured jsonb default '[]'`, `best_times jsonb default '{}'`, `updated_at`. `grant select to anon, authenticated`; policy `select using (true)`. Maintained only by `public.profiles_public_sync()`, an `after insert or update` trigger on `profiles` and `lesson_progress`: if `public_profile` upsert `{id, handle, level, best_times = jsonb_object_agg(lesson_id, best_secs) over the user's lesson_progress where best_secs is not null}`; else delete the row.

**`attempts`**: `id uuid pk` (**client-generated**), `user_id uuid not null references public.profiles on delete cascade`, `lesson_id text not null check (lesson_id ~ '^[a-z0-9-]{1,64}$')`, `mode text check (mode in ('guided','solo','timed'))`, `secs numeric(8,2) null check (secs >= 0 and secs <= 86400)`, `keystrokes int default 0 check (keystrokes >= 0)`, `mouse_count int default 0 check (>= 0)`, `assisted bool default false`, `source text default 'live' check (source in ('live','guest'))`, `client_at`, `created_at default now()`. Index `(user_id, created_at desc)`. Policy `select using (user_id = auth.uid())`.

**`lesson_progress`** (derived, never client-written): `user_id, lesson_id, completed bool, solo bool, timed bool, best_secs numeric(8,2), started_at, first_completed_at, last_at, completions int default 0`, pk `(user_id, lesson_id)`. Policy `select using (user_id = auth.uid())`.

**`events`** (§12): `id bigint generated always as identity pk`, `user_id uuid null`, `session_key text`, `name text check (name ~ '^[a-z_]{1,40}$')`, `props jsonb default '{}'`, `at default now()`. No client select. `rpc_track(p_name text, p_props jsonb default '{}', p_session_key text default null) returns void` is the one function also granted to `anon`; it stores `auth.uid()` (may be null) and skips the not-signed-in check. Client fires: `landing_view, lesson_start, lesson_complete, signup, sign_in, carry_over` (props `{lesson_id, mode}` where relevant).

`public.apply_attempt(a public.attempts)` (internal, no grants): upsert `lesson_progress` mirroring progress.js (`completed=true`; `solo=true` if mode='solo'; `timed=true` if mode='timed'; `best_secs=least(best_secs, secs)` only when `mode='timed' and not assisted and mouse_count=0 and secs is not null`; `completions+1`, `first_completed_at` once, `last_at=now()`). XP into `profiles.xp`: first completion of a lesson 100, or 60 if assisted with the remaining 40 on a later unassisted `solo`/`timed` attempt; later completions 10 each, at most 5 paid repeats per lesson; no speed bonus. `level = 1 + floor(sqrt(xp/100))`.

RPCs:
- `rpc_record_attempt(p jsonb) returns public.lesson_progress` — require keys `id, lesson_id, mode` with the types/ranges above (raise `'bad attempt'`), ignore any `user_id`/`source` in the payload, `insert … on conflict (id) do nothing`; if inserted call `apply_attempt`; always return the row. Same id twice is a no-op (double-count guard).
- `rpc_carry_over(p_guest_id uuid, p_attempts jsonb, p_skipped text[], p_experience text, p_theme text) returns table(lessons int, bests int)` — raise `'already carried'` if `carried_at is not null`; set `carried_guest_id` first so the unique index raises `unique_violation` (re-raise as `'carried to another account'`) when that guest blob went elsewhere; insert each attempt with `source='guest'` (guided ones may have `secs null`) via the same validation and `apply_attempt`; set `skipped_lessons, experience, theme, first_run_done=true`.
- `rpc_set_handle(p_handle text) returns public.profiles` — regex → `'bad handle'`; `public.banned_words(word text)` table, `position(word in lower(p_handle)) > 0` → `'not allowed'`; `handle_changed_at > now() - interval '1 day'` → `'try again tomorrow'`; `unique_violation` → `'taken'`.
- `rpc_set_profile(p jsonb) returns public.profiles` — whitelist `theme (text ≤ 32), public_profile, show_school, skipped_lessons (text[] ≤ 500), experience, first_run_done`; anything else raises.
- `rpc_my_progress(p_after text default '', p_limit int default 200) returns setof public.lesson_progress` — `where user_id = auth.uid() and lesson_id > p_after order by lesson_id limit least(p_limit, 500)`; client loops until a short page.
